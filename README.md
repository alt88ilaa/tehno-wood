## Описание проекта
Сайт-лендинг мебельной фабрики «Tehno-Wood», специализирующейся на изготовлении дизайнерских диванов и мягкой мебели по индивидуальным проектам.

## Реализованный функционал
- **Семантическая верстка:** HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`).
- **Стилизация:** CSS3 (Flexbox для раскладки блоков и навигации, CSS Grid для блока статистики, методология БЭМ).
- **Интерактив (JavaScript):**
  - Переключение светлой и темной тем оформления с сохранением в `localStorage` (Лабораторная №8).
  - Карусель/слайдер портфолио с защитой от прокрутки за пределы граничных слайдов (Лабораторная №10).
- **Серверная часть (PHP):**
  - Обработка формы заявки методом `POST`.
  - Валидация входных данных на сервере (длина полей $\ge 6$ символов) и счетчик попыток отправки через PHP Sessions (Лабораторные №13 и №14).
- **Хостинг:** развернуто на GitHub Pages.
